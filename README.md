# Beaver Valley

Official static website for Jeremy Thorn’s game. The public guide covers Story Mode, the cast and world, the playable modes, and development plans.

| Page | Contents |
| --- | --- |
| [The Valley](index.html) | Game overview and available modes |
| [Features](features.html) | Town simulation, combat, investigations, music, minigames and other systems |
| [Naval Combat](naval.html) | Ocean Operations missions, shipboard stations and crew, and a searchable [directory of 65 vessels, aircraft and fittings](naval.html#vessel-directory) with gameplay photographs and in-game stats |
| [World](world.html) | Gameplay photographs from around the town and fleet |
| [Cast](characters.html) | Searchable cast directory |
| [Guide](guide.html) | Controls and guidance for play |
| [Roadmap](roadmap.html) | Current features and design plans |
| [Support](donate.html) | The creator’s existing contribution tiers |

The site runs directly from HTML, CSS and JavaScript. Run `python -m http.server 8777` from this directory for a local preview. GitHub Pages serves the public site.
